# Aplikasi Absensi Guru Sekolah

Sistem pencatatan kehadiran guru per jam pelajaran oleh sekretaris murid di kelas melalui aplikasi mobile, dengan pengelolaan data, pemantauan real-time, dan rekapitulasi laporan oleh Admin melalui panel web.

## Struktur Repositori
- `backend/`: API (Laravel 11 + Laravel Sanctum) & Panel Admin Web (Filament v3)
- `mobile/`: Aplikasi mobile Android untuk sekretaris kelas (React Native Expo Router + TypeScript)
- `docs/`: Dokumentasi arsitektur, API endpoints (`API.md`), keputusan teknis (`DECISIONS.md`), dan panduan rilis (`DEPLOY.md`)
